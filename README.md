# Jogo do Mario - Desviar Obstáculos

Este é um jogo simples inspirado no Mario, desenvolvido com **HTML**, **CSS** e **JavaScript**.  
O objetivo do jogo é controlar o Mario para desviar de obstáculos que se aproximam enquanto ele corre automaticamente.

> 🎓 **Projeto acadêmico** realizado com base no vídeo tutorial de [Manual do Dev](https://www.youtube.com/watch?v=r9buAwVBDhA).  
> Este repositório é de uso educacional e não tem fins lucrativos ou comerciais.

---

## 🚀 Tecnologias Utilizadas

- **HTML5** – Estrutura básica do jogo  
- **CSS3** – Estilização e animações  
- **JavaScript** – Lógica do jogo e controle do personagem

## ✅ Requisitos para rodar o projeto

Para rodar o jogo localmente, basta:

1. Ter um navegador moderno instalado (ex: Chrome, Firefox, Edge)
2. Baixar os arquivos do repositório
3. Abrir o arquivo `index.html` no navegador
